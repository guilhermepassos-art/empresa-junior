## Como rodar localmente

### Pré-requisitos

- Navegador web atualizado (Chrome, Edge ou Firefox)
- Visual Studio Code
- Extensão Live Server (opcional, recomendada)

### Passo a passo
1. Baixe o projeto em Code, depois Download ZIP, ou clone pelo terminal:

```
git clone https://github.com/guilhermepassos-art/empresa-junior.git
```

2. Extraia a pasta em qualquer diretório do computador.
3. Abra a pasta no Visual Studio Code pelo menu File, depois Open Folder.
4. Clique com o botão direito no arquivo index.html e escolha Open with Live Server.
5. O navegador abre automaticamente no endereço http://127.0.0.1:5500.

### Alternativa sem Live Server

Dê dois cliques no arquivo index.html. O site abre direto no navegador.
